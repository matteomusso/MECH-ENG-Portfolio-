Matteo Musso portfolio
======================
index.html  = the whole website (edit the content block near the top of the file).
images/     = put pictures here, named exactly as the placeholders say
              (hero.jpg, profile.jpg, project-1/cover.jpg ... project-5/cover.jpg, etc.).
videos/     = optional video files.
resume/     = put your PDF here as Matteo-Musso-Resume.pdf
To view: double-click index.html. To publish free: upload this whole folder to GitHub Pages, Netlify or Cloudflare Pages.
